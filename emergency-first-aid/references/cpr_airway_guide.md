# 心肺复苏与气道急救指南

## 一、心肺复苏 (CPR)

**适用**：成人/儿童/婴儿无意识且无正常呼吸。

### 第 1 步：确认现场安全

确保现场无车辆、火灾、触电、坍塌等危险。如触电场景，先断电或用绝缘物挑开电源。

### 第 2 步：判断意识与呼吸

- 拍双肩 + 大声喊"你怎么了？"
- 观察 5-10 秒胸口有无起伏
- **无意识 + 无呼吸（或仅有喘息）** → 立即开始 CPR

### 第 3 步：呼救

**立即拨打 120**，说明：位置、有人昏迷正在做CPR、需要AED（如有）。

### 第 4 步：胸外按压（成人）

1. 伤者仰卧于**坚硬平坦**的地面（不要在软床上按）
2. 施救者跪在伤者身侧，双手重叠，掌根放在**两乳头连线中点（胸骨下半部）**
3. 双臂伸直，肩膀正对伤者胸口上方，用身体重量下压
4. **按压深度：5-6 厘米**
5. **按压频率：100-120 次/分钟**（节奏参照《Stayin' Alive》副歌）
6. 每次按压后让胸廓完全回弹，手不离开胸壁
7. **连续按压 30 次**

### 第 5 步：人工呼吸（如愿意且有能力）

1. 压额抬下巴，打开气道（怀疑颈椎损伤时用推举下颌法）
2. 捏住鼻子，包住嘴，吹气 1 秒，看到胸廓起伏即可
3. **吹 2 次**
4. 按压与吹气比例 = **30:2**，循环进行

> 如不愿做人工呼吸，可做**单纯胸外按压CPR**（只按压不间断），同样有效。

### 第 6 步：使用 AED（如有）

1. 开机，按语音提示操作
2. 贴电极片（右锁骨下 + 左乳头外侧下方）
3. AED 分析心律时所有人不接触伤者
4. 如提示需要电击，确认无人接触后按电击键
5. 电击后立即继续 CPR，不要停

### 第 7 步：持续到何时

- 伤者恢复呼吸/有反应
- 专业救援到达
- 施救者精疲力竭（换人继续）
- 现场不安全

### 儿童 CPR（1岁-青春期）

- 按压深度：约为胸廓厚度的 **1/3**（约 5 厘米）
- 单手按压（小儿童可用单手）
- 按压频率：100-120 次/分钟
- 按压吹气比：**30:2**（单人）或 **15:2**（双人）
- 人工呼吸：小口吹气，避免过度

### 婴儿 CPR（1岁以下）

- 按压位置：两乳头连线正下方
- 用**两根手指**按压
- 按压深度：约 4 厘米（胸廓 1/3）
- 人工呼吸：用嘴包住婴儿口鼻，轻吹（腮帮微鼓即可）
- 按压吹气比：**30:2**（单人）或 **15:2**（双人）

## 二、气道梗阻 — 海姆立克急救法

**适用**：异物堵塞气道，伤者无法呼吸/说话/咳嗽。

### 判断是否梗阻

| 表现 | 处理 |
|------|------|
| 能咳嗽、能说话 | **不要干预**，鼓励用力咳嗽，异物可能自行咳出 |
| 不能说话/咳嗽、双手抓脖子（V字手势）、面色青紫 | **立即施救** |

### 成人/儿童（1岁以上）— 腹部冲击法

1. 站在伤者身后，双腿分开站稳（一腿在前一腿在后）
2. 一手握拳，**拳眼（拇指侧）**放在伤者**肚脐上方两横指处**
3. 另一手包住拳头
4. **快速向内向上**猛烈冲击腹部
5. 重复冲击，每次都是独立有力的动作
6. 直到异物排出或伤者失去意识

> 伤者失去意识 → 立即开始 CPR（先查看口腔有无异物，有则取出，无则继续按压）

### 婴儿（1岁以下）— 拍背压胸法

1. 将婴儿面朝下趴在前臂上，手托住婴儿头部和下颌
2. 用手掌根部**拍击婴儿背部（肩胛之间）5 次**
3. 翻转婴儿面朝上，用两指在两乳头连线正下方**快速按压 5 次**
4. 交替进行：5次拍背 + 5次压胸
5. 直到异物排出或婴儿失去意识

> 婴儿失去意识 → 开始婴儿 CPR，每次吹气前查看口腔有无异物

### 孕妇/肥胖者 — 胸部冲击法

拳头位置改为**胸骨中部**（与CPR按压位置相近），向内冲击。

### 自救（独自一人时）

1. 自己握拳冲击腹部（同海姆立克手法）
2. 或将上腹部靠在**椅子靠背/桌边/栏杆**等硬物上，快速向上冲击
3. 反复进行直到排出

## 三、复原体位（侧卧位）

**适用于**：有呼吸但无意识的伤者。

1. 伤者仰卧，施救者跪在伤者身侧
2. 将伤者靠近你一侧的手臂伸出，与身体成直角
3. 将伤者另一只手放在对侧脸颊上
4. 用一只手拉起伤者远侧膝盖，另一手扶住伤者脸颊
5. 向你方向拉膝盖，将伤者翻向你
6. 调整上方腿弯曲以保持稳定
7. 确保伤者头部后仰，气道通畅
