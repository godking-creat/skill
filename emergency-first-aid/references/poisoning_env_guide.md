# 中毒与环境伤害急救指南

## 一、中毒

### 通用原则

1. **确认毒物**：吃了什么？喝了什么？吸入了什么？接触了什么？剂量多少？时间多久？
2. **保留容器/包装**带给医生
3. **不要催吐**（除非专业人员指导）——催吐可能造成食道二次损伤或误吸

### 食物中毒

1. 症状：恶心、呕吐、腹泻、腹痛、发热
2. 补充水分和电解质（少量多次喝淡盐水/口服补液盐）
3. 如呕吐腹泻严重、脱水、高热、便血 → 就医
4. 保留剩余食物样本

### 一氧化碳中毒（煤气中毒）

1. **立即开窗通风/移到空气清新处**（施救者注意自身安全）
2. 检查意识和呼吸，无呼吸 → CPR
3. 松开衣领，保持气道通畅
4. **立即拨打 120**（需要高压氧治疗）
5. 即使清醒也要就医（迟发性脑损伤风险）

### 农药/化学品中毒

1. 皮肤接触 → 脱去污染衣物，大量清水冲洗 15 分钟以上
2. 吸入 → 移到空气清新处
3. 误食 → **不要催吐**，立即拨打 120，带上容器/标签
4. 眼睛接触 → 大量清水冲洗 15 分钟以上

### 药物过量

1. 确认药物名称和剂量
2. **不要催吐**
3. 拨打 120 或毒物咨询热线
4. 带上药物包装

### 酒精中毒

1. 轻度（兴奋/话多）→ 喝水，观察，侧卧休息
2. 中度（走路不稳/意识模糊）→ 侧卧防误吸，不要让其独处
3. 重度（昏迷/呕吐/呼吸缓慢）→ **立即拨打 120**，侧卧位，清理呕吐物

> 醉酒者**必须侧卧**（复原体位），仰卧呕吐可能窒息死亡

## 二、动物咬伤

### 狗/猫咬伤

1. **立即冲洗**：用肥皂水和流动清水交替冲洗伤口 **至少 15 分钟**
2. 用碘伏消毒
3. **不要缝合伤口**（开放引流）
4. **24 小时内接种狂犬疫苗**（越快越好）
5. 伤势重/深部伤口 → 就医（可能需要抗血清）
6. 了解咬人动物是否接种过疫苗

### 蛇咬伤

1. **保持镇定，减少活动**（减缓毒液扩散，运动越少越好）
2. **记住蛇的样子**（拍照最好，不要追蛇/打蛇）
3. **立即拨打 120**
4. 伤肢固定在低于心脏的位置
5. **取下伤肢上的戒指/手镯/手表**（可能肿胀后无法取下）
6. **不要**：切开伤口、用嘴吸毒、冰敷、绑止血带、喝酒

### 蜂蜇伤

1. 用卡片（银行卡/指甲）刮除毒刺（不要用镊子夹，会挤入更多毒液）
2. 肥皂水清洗（蜜蜂毒液为酸性，用碱性肥皂水中和）
3. 冰敷消肿
4. 观察是否有过敏反应（参见急性病指南 §过敏反应）
5. 多处蜇伤/过敏体质 → 就医

### 蜱虫叮咬

1. 用尖头镊子贴近皮肤，夹住蜱虫头部，**平稳向上拔出**（不要扭转/挤压腹部）
2. 拔出后用碘伏/酒精消毒
3. **不要**用烟头烫/涂凡士林/涂酒精（蜱虫受刺激会吐出更多病原体）
4. 如出现发热/皮疹/关节痛 → 就医（可能感染莱姆病）

## 三、触电

1. **先断电！** 拉闸/拔插头/用干燥绝缘物（木棍/塑料/橡胶）挑开电源
2. **不要在带电状态下接触伤者**
3. 确认断电后检查意识和呼吸
4. 无呼吸 → 立即 CPR
5. 检查出入口伤（触电部位和接地部位）
6. 电击伤可能导致心律失常，**即使清醒也必须就医**
7. 大面积烧伤 → 参见创伤指南 §烧烫伤处理

## 四、异物入体

### 异物入眼

1. **不要揉眼！**
2. 轻轻眨眼让泪液冲洗
3. 用清水/生理盐水冲洗眼睛 15 分钟
4. 如异物在上眼睑内 → 翻开上眼睑用湿棉签轻拭
5. 如异物嵌入眼球/金属碎片 → **不要自行取出**，覆盖双眼送医

### 异物入鼻（常见于儿童）

1. 让孩子用嘴呼吸
2. **堵住未堵塞的那侧鼻孔**，让孩子轻轻擤出来
3. 如擤不出 → **不要用镊子/钩子自行取**（可能推更深），就医

### 异物入耳

1. 活昆虫：用手电照耳道引其爬出，或滴矿物油使其窒息后倒出
2. 其他异物：**不要自行掏**，就医
