### 急救箱维护

- 每季度检查一次，清理过期药品
- 急救箱放在**全家都知道且容易拿到**的位置
- 避免放在潮湿/高温处
- 外出旅行准备便携急救包

## 二、急救电话速查

| 电话 | 用途 |
|------|------|
| **120** | 医疗急救 |
| **119** | 火警/消防救援 |
| **110** | 报警/治安 |
| **122** | 交通事故 |
| **12320** | 全国公共卫生公益热线（可咨询中毒/传染病） |
| **心理援助热线 400-161-9995** | 心理危机干预 |

### 拨打 120 时要说清

1. **位置**：详细地址（XX路XX号XX小区XX栋XX室），如不确定说附近标志性建筑
2. **情况**：伤者人数、伤情/病情、是否意识清醒/有呼吸
3. **正在做什么**：如"正在做心肺复苏"
4. **联系电话**：保持电话畅通，不要占线
5. **等接线员挂断后再挂**——可能有补充询问

## 三、常见急救误区纠正

| 误区 | 正确做法 |
|------|----------|
| 掐人中可以救晕倒的人 | 掐人中无科学依据；正确做法是检查呼吸、抬高双腿、保持气道通畅 |
| 溺水要先控水 | 控水浪费时间且无效；上岸后直接检查呼吸，无呼吸立即CPR |
| 烫伤涂牙膏/酱油 | 会增加感染风险、影响判断伤情；正确做法是冷水冲洗15-30分钟 |
| 癫痫发作往嘴里塞东西 | 会硌碎牙齿/导致窒息；正确做法是保护头部、不按压肢体 |
| 伤口涂酒精消毒 | 酒精刺激组织影响愈合；正确做法是用碘伏或生理盐水 |
| 蛇咬伤用嘴吸毒 | 口腔黏膜吸收毒液会中毒；正确做法是固定伤肢、保持镇定、等救援 |
| 扭伤后立刻热敷揉搓 | 会加重肿胀出血；正确做法是RICE原则（休息/冰敷/加压/抬高） |
| 鼻出血仰头 | 血液流入咽喉可能引起呕吐/误吸；正确做法是头前倾、捏鼻翼 |
| 食物中毒催吐 | 可能造成食道二次损伤或误吸；正确做法是保留样本、及时就医 |
| 心梗患者自行驾车就医 | 路上可能发生心脏骤停；正确做法是拨打120、保持安静等待救援 |

## 四、急救培训建议

### 推荐培训

| 培训 | 内容 | 获取途径 |
|------|------|----------|
| 红十字会急救员证 | CPR/AED/止血包扎/骨折固定等 | 当地红十字会 |
| AHA Heartsaver | CPR/AED/ choking | 美国心脏协会认证机构 |
| 急救知识讲座 | 基础急救常识 | 社区/企业/学校组织 |

### 建议掌握的核心技能

1. **CPR（心肺复苏）**：成人/儿童/婴儿
2. **海姆立克急救法**：成人/儿童/婴儿/自救
3. **AED 使用**：开机后按语音提示操作即可
4. **止血包扎**：直接压迫法/加压包扎
5. **复原体位**：有呼吸无意识时的标准体位
6. **FAST 识别**：脑卒中早期识别

### 定期复习

- 急救技能不用会生疏，建议**每年至少复习一次**
- 关注急救指南更新（如 CPR 按压深度/频率标准可能微调）
- 家庭成员一起学习，确保不止一人会急救
