# 家庭清洁指南

## 按频率分类

### 每日（5-15 分钟）
- 整理床铺
- 厨房台面擦拭
- 洗碗/整理碗碟
- 简单扫地（高频区域）
- 垃圾丢弃（厨余垃圾每日带出门）
- 快递包装拆完即扔

### 每周（30-60 分钟）
- 全屋拖地/吸尘
- 卫生间全面清洁（马桶、洗手盆、镜子、地面）
- 更换床单被套
- 擦拭桌面、窗台、电器表面灰尘
- 冰箱内过期食物检查

### 每两周
- 淋浴间/浴缸深度清洁
- 洗衣机清洁（槽清洁剂运行一次）
- 微波炉/烤箱内部清洁
- 门把手、开关面板消毒

### 每月
- 窗帘/沙发套除尘或清洗
- 灯具表面灰尘
- 衣柜整理、换季衣物检查
- 抽油烟机滤网清洗
- 下水道疏通预防

### 每季度
- 窗户玻璃内外
- 冰箱后方/底部除尘
- 床垫翻转/吸尘
- 空调滤网清洗
- 地毯深度清洁

### 每半年
- 窗帘水洗/干洗
- 床底、柜顶等盲区清洁
- 厨房柜子内部整理
- 书籍/装饰品除尘
- 洗衣机筒自洁（高温空洗）

## 按房间快速清单

### 厨房（油污重灾区）
- [ ] 灶台和墙面去油

### 卫生间（潮湿、霉菌）

- [ ] 淋浴区除霉
- [ ] 洗手盆 + 水龙头除水垢
- [ ] 镜子擦亮
- [ ] 排气扇除尘
- [ ] 地漏清理
- [ ] 地面消毒

### 卧室

- [ ] 床头柜擦拭
- [ ] 地面吸尘/拖地
- [ ] 窗帘除尘
- [ ] 衣柜表面擦拭

### 客厅
- [ ] 地面吸尘 + 拖地
- [ ] 茶几/电视柜/边桌擦拭

- [ ] 遥控器/开关消毒
- [ ] 绿植叶片擦拭
- [ ] 地毯吸尘

## 高效清洁原则

1. **从上到下**：先擦高处（柜顶、灯具），最后拖地
2. **从干到湿**：先除尘，再湿擦
3. **从里到外**：从房间内部往门口方向清洁
4. **清洁剂先敷后擦**：喷后静置 2-5 分钟再擦，效果翻倍
5. **15 分钟原则**：每个区域不纠缠，15 分钟到点就收工换区
6. **顺手原则**：淋浴时顺手刷瓷砖，做饭间歇顺手擦灶台

## 常见难题速查

| 问题 | 方案 |
|------|------|
| 水龙头水垢 | 白醋浸湿纸巾包裹，敷 30 分钟后擦拭 |
| 微波炉油污 | 柠檬水加热 3 分钟，蒸汽软化后一擦即净 |
| 冰箱异味 | 小苏打敞口放置 + 定期清理过期食品 |
| 瓷砖缝发霉 | 小苏打 + 双氧水调糊，涂上静置 30 分钟刷掉 |
| 烧焦的锅底 | 小苏打 + 水煮开，浸泡过夜 |
| 地毯污渍 | 小苏打撒上吸味，白醋水喷后吸干 |
| 淋浴头堵塞 | 白醋袋绑在喷头上浸泡过夜 |
| 洗衣机异味 | 每月用专用槽清洁剂或白醋+小苏打空洗一次 |
