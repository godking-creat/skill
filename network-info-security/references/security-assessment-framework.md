# 安全评估框架

## 概述

本文档定义了网络信息安全评估的标准框架，涵盖 Web 应用、网络基础设施、移动应用和云环境四大评估领域。评估时根据用户描述的目标系统类型，选择对应领域的检查项进行逐项分析。

---

## 一、Web 应用安全评估

基于 OWASP Top 10 (2021) 框架，覆盖以下风险类别：

### A01 - 失效的访问控制
- 验证水平/垂直权限隔离是否到位
- 检查未认证 API 端点是否暴露敏感功能
- 确认目录遍历防护是否生效
- 检查会话令牌是否可预测或可重用

### A02 - 加密机制失效
- 确认全站 HTTPS 强制跳转
- 检查 TLS 版本是否 >= 1.2，禁用 SSLv3/TLS 1.0/1.1
- 验证敏感数据传输和存储是否加密
- 检查密码哈希算法是否使用 bcrypt/argon2/scrypt

### A03 - 注入
- 检查 SQL 注入防护（参数化查询、ORM）
- 检查命令注入防护
- 检查 LDAP/XPath/NoSQL 注入风险
- 验证 ORM 框架是否正确使用（无原生拼接）

### A04 - 不安全设计
- 评估业务逻辑是否存在竞态条件
- 检查关键操作是否有防重放机制
- 验证敏感操作是否需要多因素认证

### A05 - 安全配置错误
- 检查默认凭据是否已修改
- 检查错误信息是否泄露堆栈/路径
- 确认调试模式在生产环境中已关闭
- 检查 HTTP 安全头（CSP, HSTS, X-Frame-Options, X-Content-Type-Options）

### A06 - 易受攻击和过时的组件
- 检查依赖库版本是否存在已知 CVE
- 检查框架版本是否为受支持版本
- 验证 SBOM（软件物料清单）是否可追溯

### A07 - 身份识别和认证失败
- 检查密码策略（长度、复杂度、历史）
- 验证登录限流和锁定机制
- 检查会话管理（超时、刷新、销毁）
- 评估多因素认证覆盖范围

### A08 - 软件和数据完整性故障
- 检查 CI/CD 管道完整性
- 验证软件更新签名验证
- 检查反序列化配置是否安全

### A09 - 安全日志和监控失败
- 检查关键安全事件是否记录
- 验证日志是否包含足够上下文（IP、用户、时间、操作）
- 确认日志篡改防护机制
- 检查告警阈值和响应流程

### A10 - 服务端请求伪造 (SSRF)
- 检查服务端 URL 获取是否校验白名单
- 检查内网地址访问限制
- 验证元数据接口（如 AWS 169.254.169.254）是否被屏蔽

## 二、网络基础设施安全评估

### 边界安全
- 防火墙规则审计（入站/出站默认拒绝策略）
- DMZ 架构合理性
- 入侵检测/防御系统 (IDS/IPS) 部署
- DDoS 防护方案

### 网络分段
- VLAN 划分是否按安全级别隔离
- 动态 VLAN 与端口安全
- 东西向流量监控
- 微分段在虚拟化环境中的应用

### 访问控制
- VPN 配置安全性（协议、认证方式、加密强度）
- 堡垒机/跳板机部署与审计
- 网络设备访问控制（SSH vs Telnet）
- NAC（网络准入控制）部署情况

### 设备安全
- 网络设备固件版本与补丁
- SNMP 社区字符串安全性（v3 vs v2c）
- 管理平面防护（CoPP/rate-limiting）
- NTP 时间同步配置

## 三、移动应用安全评估

### 数据存储
- 检查敏感数据是否使用 Keychain/Keystore 存储
- 验证本地数据库是否加密
- 检查日志中是否泄露敏感信息
- 确认剪贴板访问是否限制敏感内容

### 通信安全
- 证书绑定 (Certificate Pinning) 配置
- API 通信加密与完整性验证
- 检查 WebSocket 安全配置

### 平台交互
- 检查 Intent/Deep Link 暴露风险
- 验证 WebView 安全配置（禁用 JS、文件访问）
- 检查 ContentProvider/Activity 导出策略

### 代码安全
- 反编译/逆向防护（代码混淆、加固）
- 根/越狱检测
- 调试器检测与反调试
- 完整性校验机制

---

## 四、云环境安全评估

### 身份与访问管理 (IAM)
- 最小权限原则审计
- 检查长期密钥 vs 临时角色凭证
- MFA 强制启用范围
- 密钥轮换策略

### 网络安全
- 安全组规则最小化
- VPC/子网隔离设计
- NAT 网关与流量出口控制
- WAF 配置与规则集

### 数据安全
- 静态数据加密（KMS 管理密钥）
- 传输中数据加密
- 数据库审计日志
- 备份加密与异地容灾

### 容器与 Kubernetes
- 镜像扫描与签名验证
- Pod 安全策略/PSA
- RBAC 权限模型
- 网络策略 (NetworkPolicy)
- Secret 管理方案
