# 安全检查清单

按系统类型分组的快速检查清单，评估时逐项确认。

---

## Web 应用检查清单

### 认证与授权
- [ ] 密码策略：最短 12 位，包含大小写+数字+特殊字符
- [ ] 密码存储：使用 bcrypt/argon2，不得使用 MD5/SHA1
- [ ] 登录限流：5 次失败后锁定 15 分钟
- [ ] 会话超时：闲置 30 分钟自动过期
- [ ] 会话令牌：使用加密安全的随机数生成
- [ ] Cookie 安全：HttpOnly + Secure + SameSite
- [ ] 权限校验：每个 API 端点均校验用户权限
- [ ] 水平越权：用户 A 不能访问用户 B 的数据
- [ ] 垂直越权：普通用户不能访问管理员功能
- [ ] MFA：关键操作（修改密码、资金操作）强制 MFA

### 输入验证与输出编码
- [ ] 所有用户输入在服务端校验
- [ ] SQL 查询使用参数化查询或 ORM
- [ ] 模板引擎自动转义 XSS（或手动转义）
- [ ] 文件上传校验类型、大小、内容
- [ ] 文件下载路径校验（防目录遍历）
- [ ] 命令执行使用参数化方式，禁用 shell 拼接
- [ ] XML 解析禁用外部实体 (XXE)
- [ ] 反序列化使用安全配置或白名单

### 传输与存储
- [ ] 全站 HTTPS，HTTP 自动跳转
- [ ] TLS >= 1.2，禁用弱加密套件
- [ ] HSTS 头已配置（max-age >= 31536000）
- [ ] 敏感数据传输加密
- [ ] 数据库中敏感字段加密存储
- [ ] 密钥管理使用 KMS/HSM，不硬编码
- [ ] 备份数据加密

### 安全配置
- [ ] 默认凭据已修改
- [ ] 错误页面不泄露堆栈/路径信息
- [ ] 调试/测试接口在生产环境已移除或禁用
- [ ] HTTP 安全头：CSP, X-Frame-Options, X-Content-Type-Options
- [ ] CORS 配置最小化，不使用通配符
- [ ] 依赖库版本为安全版本（无已知 CVE）
- [ ] 容器以非 root 用户运行

### 日志与监控
- [ ] 登录成功/失败记录
- [ ] 权限变更记录
- [ ] 敏感数据访问记录
- [ ] 日志不包含密码/令牌等敏感信息
- [ ] 日志集中存储且防篡改
- [ ] 异常行为告警机制

## 网络基础设施检查清单

### 防火墙与边界
- [ ] 默认拒绝策略（仅放行已知必要流量）
- [ ] 出站规则已配置（不仅限入站）
- [ ] 管理端口不暴露到互联网
- [ ] 防火墙规则定期审计（每季度）
- [ ] 防火墙配置变更需审批

### 网络隔离
- [ ] 办公网/生产网/DMZ 物理或逻辑隔离
- [ ] 数据库网段不直接面向应用网段以外
- [ ] 管理网段独立隔离
- [ ] 访客 Wi-Fi 与内部网络隔离

### 设备安全
- [ ] 网络设备仅允许 SSH 管理
- [ ] 设备管理需通过堡垒机
- [ ] 固件版本为厂商支持版本
- [ ] SNMP 使用 v3（禁用 v1/v2c 默认社区）
- [ ] NTP 时间同步已配置
- [ ] 设备配置定期备份且加密存储

### 入侵检测
- [ ] 关键网段部署 IDS/IPS
- [ ] 告警规则覆盖常见攻击模式
- [ ] 告警有值班响应流程
- [ ] 流量分析覆盖东西向流量

## 云环境检查清单

### IAM
- [ ] 遵循最小权限原则
- [ ] 无长期 Access Key（使用角色/临时凭证）
- [ ] Root/管理员账户 MFA 已启用
- [ ] 所有人类用户 MFA 已启用
- [ ] 密钥定期轮换（<= 90 天）
- [ ] 权限定期审计（每季度）

### 网络安全
- [ ] 安全组规则最小化
- [ ] 0.0.0.0/0 入站规则已审计
- [ ] 数据库不在公网
- [ ] VPC 流日志已启用
- [ ] NAT 网关控制出站流量

### 数据安全
- [ ] EBS/磁盘加密已启用
- [ ] S3/对象存储默认加密
- [ ] 数据库加密已启用
- [ ] KMS 密钥轮换已配置
- [ ] 备份加密且跨区域复制

### 容器安全
- [ ] 镜像来自可信仓库
- [ ] 镜像扫描已配置
- [ ] 容器以非 root 运行
- [ ] Pod 安全策略/PSA 已配置
- [ ] NetworkPolicy 限制 Pod 间通信
- [ ] Secret 不以明文存储在镜像或环境变量中

---

## 通用安全检查清单

### 补丁管理
- [ ] 操作系统补丁在 30 天内部署
- [ ] 应用依赖补丁在 14 天内部署
- [ ] 安全补丁（严重级别）在 72 小时内部署
- [ ] 补丁部署前在测试环境验证

### 数据保护
- [ ] 敏感数据分类分级
- [ ] 数据保留策略已定义
- [ ] 数据销毁流程已建立
- [ ] DLP（数据防泄漏）部署

### 应急响应
- [ ] 安全事件响应计划已制定
- [ ] 应急联系人清单已更新
- [ ] 每年至少一次应急演练
- [ ] 事件取证能力已具备
